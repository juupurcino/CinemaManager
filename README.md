# CinemaManager
CinemaManager is console-based system in C# for managing movies, sessions, and ticket sales efficiently.

1. Manage Movies

Add, list, edit, and remove movies.
Each movie should have a title, genre, age rating, duration, and screening times.

2. Manage Rooms

Add, list, and remove rooms.
Each room should have a number, seating capacity, and status (available/occupied).
Manage Sessions

3. Create sessions by associating a movie with a room and setting a time.
   
Check if the room is available at the selected time.
Ticket Sales

4. Register ticket sales for sessions.

Verify seat availability in the room before confirming sales.

6. Reports

Display a list of sessions with the number of tickets sold.
Show the most-watched movies.
